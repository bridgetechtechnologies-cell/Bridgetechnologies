# Bridge Technology

Bridge Technology is a responsive course and enrollment website for a technology education provider. It presents course information, student success stories, FAQs, contact details, and a registration form.

**Website:** [bridgetechnology.in](https://bridgetechnology.in)

## Features

- Responsive landing page with course categories and expandable course curricula
- About, learning process, instructor and placement information, testimonials, FAQs, and contact sections
- Student registration form with required-field validation
- Registration API that saves submissions to an Excel workbook
- Privacy policy and terms of service pages
- Sitemap and robots.txt generation

## Tech stack

- Next.js 16 with the App Router
- React 19 and TypeScript
- Tailwind CSS 4
- Lucide icons
- XLSX for registration workbook storage

## Requirements

- Node.js 20.9 or later
- npm

## Getting started

Install dependencies and start the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Available commands

| Command | Description |
| --- | --- |
| `npm run dev` | Start the local development server |
| `npm run lint` | Run ESLint |
| `npm run build` | Create a production build and generate the sitemap |
| `npm run start` | Start the production server after building |

To run the production app locally:

```bash
npm run build
npm run start
```

## Registration storage

The registration form sends a `POST` request to `/api/register`. The API validates the required name, email, phone, and course fields, then writes registrations to:

```text
data/registrations.xlsx
```

The `data` directory and workbook are created when the first registration is received. The deployment environment must allow the application to write to its local filesystem. On serverless or ephemeral hosting, this file may not persist between runs or scale across multiple instances; use durable shared storage for those deployments.

The request body accepts `name`, `email`, `phone`, and `course`; `qualification` and `message` are optional. A `timestamp` may be supplied by the client or is generated by the API.

## Sitemap configuration

The sitemap defaults to `https://bridgetechnology.in`. To use another canonical site URL when generating it, set `SITE_URL` in the environment:

```env
SITE_URL=https://example.com
```

## Editing site content

Company details, navigation labels, course descriptions, course curricula, statistics, and other landing-page content are maintained in [`src/lib/data.ts`](./src/lib/data.ts). The homepage assembles its sections in [`src/app/page.tsx`](./src/app/page.tsx).

## Deployment

Build and run the app with the production commands above, or deploy it to a platform that supports Next.js. Configure `SITE_URL` if the canonical domain differs from the default, and ensure the registration storage is durable and writable for the selected hosting platform.
